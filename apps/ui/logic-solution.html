Smart Ticket Fill F-SVC-001 Phase 1 · trial ready

Generate ticket draft from conversation and write to Shared output

Control Loop

Act

Tools (boundary)

Tool class read + write_govern. This feature uses: Read business entities (Customer, Vehicle, Ticket, Ticket list); Structure / write shared / gate (Extract ticket fields, Suggest topic tags, Tag dictionary, Write shared output).

Interaction mode

Collaborative — Business initiates multi-step lookup/fill; shared write requires allowlist

Skill build logic

"Smart Ticket Fill" capability pack build logic (fill_ticket · Act)

  1. Which business data / knowledge:Customer, vehicle, existing tickets (master data); tag dictionary when needed
  2. What processing:Verify identity and open tickets → extract ticket fields and suggest topic tags from conversation → assemble ticket draft
  3. Which model / loop:Act loop: decide what to look up and when to write; rule tools can assist field extraction
  4. Which tools:Read customer/vehicle/ticket; extract fields and tag; write shared output for renewal etc.
  5. Output and downstream use:Ticket draft + complaint tags to shared layer; one run fills ticket only, no auto outreach
